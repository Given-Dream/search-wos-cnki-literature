# Rock-fracture example profile

This directory is a domain example only. It is not the Skill's default topic.

The example uses four independent pools:

- Q1: rock fracture ∩ DIC;
- Q2: rock fracture ∩ DIC ∩ fracture-pattern characterization;
- Q3: rock fracture pattern ∩ clustering/unsupervised discovery;
- Q4: rock fracture pattern ∩ graph learning/GNN/topology.

The paired WOS and CNKI query files are under `queries/`. They demonstrate title-led precision adjustments while preserving each pool's semantic meaning.
